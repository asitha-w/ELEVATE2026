The Number
One honest before/after on the declared pillar
Real, or felt? Builders can't feel their own speedup — METR's trial: devs believed +20%, measured −19%. Testimony is a claim; a number with a baseline is a result.
Vibes; self-reported speedup, no measurement
A real number with a rough baseline; honest about what it misses
Clean before/after on the real project; survives "how did you measure that?"
2
The Offering
Would this customer adopt it and pay for it?
Having a customer scores nothing — every project team has one. Scored: a named user whose Monday changes · the workflow it lands in · cost-per-run vs value-per-run · the honest gap list before 99x can sell it.
A demo with no named user, no workflow, no cost story
Named user & workflow; rough cost-to-run; honest gap list
User + workflow + unit economics + path past pilot — 99x could scope the offering from this pitch
3
The Stress Test
Break it on purpose — does the gate hold?
No agent never fails; trustworthy = failure gets caught. Team demos a deliberate failure → gate catches it. Judges probe the edges in Q&A: "it can't break" is a red flag; "it breaks at X, the gate contains it" is a top answer.
No failure shown, or the gate is a confirm-click; "it can't break"
Failure demonstrated; human catches it, recovery is manual
Human rejects/edits, agent incorporates it; team knows its boundary, states oversight numbers
4
Beyond the Demo
Does this change how the project works?
Bolt-ons don't create value — redesigns do (McKinsey: high performers 3.6× more likely to redesign the workflow). The tell: the team can name what they stopped doing. Winners must be repeatable by other 99x teams.
A bolt-on beside the real workflow; nothing stopped
Workflow actually changed; team can say what they stopped doing
Redesigned around the agent + transferable — another 99x team could adopt it from this pitch

Q&A prompts — probe the edges

Why does this need to be an agent? · How did you measure that — what does it miss? · What does one run cost vs. what is one run worth? · What happens when the input is ambiguous, not wrong? · What breaks first at 10× usage? · What ships if the human rubber-stamps for a week? · Which failure would you not catch? · What did the floor crew challenge, and what changed?
