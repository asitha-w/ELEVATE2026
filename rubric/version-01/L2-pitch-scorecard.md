# Level 2 — Pitch Scorecard (panel, whole company watching) · v01 DRAFT

**Purpose:** prove the solution is an offering — something 99x can put in front of
the real customer.
**Who:** the full panel; every judge sees all 8 finalists, so absolute scoring is
safe here (unlike the floor round).
**Output:** ~3 winners; panel also recommends which entries go to the 99x expert
panel → customer as real offerings. Winners need not be the only recommendations.
**Format:** fresh scores — floor scores do NOT carry into L2 (they feed the surface
awards only). 3 of the panel ideally saw the team on the floor, giving both
fresh-eyes and continuity perspectives.

## The four axes (0–5 each, equal weight → max 20)

### 1. Measured Elevation — "what's the number?"

*One honest before/after on the declared surface.*

| Score | Anchor |
|---|---|
| 0–1 | Vibes; self-reported speedup with no measurement (the METR trap) |
| 2–3 | A real number with a rough baseline; honest about what it doesn't capture |
| 4–5 | Clean before/after on the real project; the team can defend the measurement method under Q&A |

### 2. Customer Readiness — "who uses this on Monday?"

*The pilot→production chasm is where most agentic projects die (Gartner: 40%+
canceled by 2027; top cause: unclear business value).*

| Score | Anchor |
|---|---|
| 0–1 | A demo with no owner, no user, no cost story |
| 2–3 | Named user and workflow; rough cost-to-run; honest gap list before it ships |
| 4–5 | Named customer + user + workflow, unit economics (cost per task vs. value per task), and a credible path past pilot — what 99x must do to offer this |

### 3. Trustworthy Autonomy — "does the gate hold under stress?"

*Demonstrate a failure on purpose: the agent gets it wrong, the human catches it.*

| Score | Anchor |
|---|---|
| 0–1 | No failure shown, or gate is a confirm-click |
| 2–3 | Failure demonstrated; human catches it, recovery is manual |
| 4–5 | Failure demonstrated; gate surfaces why, human rejects/edits, agent incorporates the correction; team can state oversight numbers (e.g. intervention rate, cost of a missed catch) |

### 4. Elevation Beyond the Demo — "does this change how the project works?"

*McKinsey: value correlates with workflow redesign, not tool bolt-ons (high
performers 3.6× more likely to redesign). And 99x's north star: repeatable
elevation, not one-off wins.*

| Score | Anchor |
|---|---|
| 0–1 | A bolt-on tool beside the real workflow |
| 2–3 | The project's workflow actually changed; the team can say what they stopped doing |
| 4–5 | Workflow redesigned around the agent + the pattern is repeatable on other 99x projects — the pitch tells us how another team would adopt it |

## Q&A prompts for the panel (2 questions per team)

- Why does this need to be an agent — what would the simple version miss?
- What does one run cost, and what is one run worth?
- What did the floor crew challenge you on, and what did you change since?
- What breaks first at 10× usage, and who notices?
- If the customer says yes tomorrow, what's the first thing you'd have to build
  that doesn't exist today?

## Deliberation

1. Sum scores → provisional ranking of 8.
2. Panel deliberates as one — ties broken on **Trustworthy Autonomy** (the event's
   thesis), then panel vote.
3. Select ~3 winners; separately list every entry recommended to the 99x expert
   panel as a customer offering (can exceed 3).
4. Award the five surface prizes from banked floor scores (Best Pace / Quality /
   Value / Partnership / Dev Happiness).
